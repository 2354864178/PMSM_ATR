# 架构说明

## 1. 项目目标
本项目用于仿真电机-逆变器-轴系-涡轮-泵耦合系统，采用连续域对象模型与离散控制器协同运行的结构。

## 2. 目录分层
- include: 头文件与接口定义。
- model: 物理模型、控制器、求解器实现。
- src: 主程序入口与日志输出。
- notebooks: 仿真结果绘图。
- docs: 说明文档。

## 3. 核心模块
### 3.1 组件层（Plant Components）
- 电机模型: dq 电气状态与电磁转矩计算。
- 逆变器模型: AC 侧调制输出与 DC 母线动态。
- 轴系模型: 刚性同轴机械动力学。
- 涡轮模型: 可压缩流动与扭矩输出。
- 泵模型: 液压动态与负载扭矩。

### 3.2 控制层（Controllers）
- 电流环控制器: dq PI + 前馈补偿。
- SVPWM 控制器: dq 电压参考转三相调制信号。

### 3.3 求解层（Solver）
- 全系统 RK4 求解器负责:
  - 组件耦合顺序管理。
  - 连续状态积分推进。
  - 代数量评估与状态回写。

## 4. 时序与解耦
当前采用双时间尺度:
- model_dt: 连续模型积分步长。
- control_dt: 控制器更新周期。

运行时采用零阶保持思想:
- 控制器在 control_dt 时刻更新一次输出。
- 两次更新之间，控制电压参考保持不变。

## 5. 主循环职责
主循环位于 src/main.cpp，职责包括:
- 初始化配置与模型。
- 构造传感器接口，向控制器提供测量量。
- 注入边界条件（涡轮、泵、逆变器外部输入）。
- 调用求解器推进一步并记录日志。

## 6. 可选模式
- 固定转速模式:
  - 打开 runtime.fixed_speed_mode 后，机械角速度固定为 runtime.omega_mech_fixed。
  - 适用于电流环单独测试与解耦验证。

## 7. 数据流概览
1) 控制器读取传感器量（id, iq, omega_e, v_dc）。
2) 控制器输出 ud_ref, uq_ref。
3) SVPWM 与逆变器生成三相电压。
4) 电机、涡轮、泵、轴系进行耦合评估。
5) 求解器 RK4 积分得到下一时刻状态。
6) 日志写入 build/log.xlsx，供 notebooks/plot.ipynb 绘图。
