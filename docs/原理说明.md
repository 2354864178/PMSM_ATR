# 原理说明

## 1. 总体方法
本项目采用连续对象模型 + 离散控制器的联合仿真方法:
- 对象侧用微分方程描述并由 RK4 积分。
- 控制侧按固定采样周期更新，采用零阶保持输出。

## 2. 坐标变换原理
### 2.1 Clarke 变换（abc -> alpha-beta）
alpha = 2/3 * (a - 1/2 b - 1/2 c)
beta  = 2/3 * (sqrt(3)/2 b - sqrt(3)/2 c)

### 2.2 Park 变换（alpha-beta -> dq）
d = alpha cos(theta_e) + beta sin(theta_e)
q = -alpha sin(theta_e) + beta cos(theta_e)

## 3. PMSM dq 电气模型
电角速度关系:
omega_e = p * omega_mech

电流动态:
d(id)/dt = (ud - Rs id + omega_e Lq iq) / Ld
d(iq)/dt = (uq - Rs iq - omega_e Ld id - omega_e psi_f) / Lq

电磁转矩:
T_em = 1.5 * (p/2) * (psi_f iq + (Ld - Lq) id iq)

## 4. dq 电流环控制思想
控制结构为 PI 反馈 + 前馈解耦:
- 反馈项: 根据 id, iq 误差由 PI 产生调节量。
- 前馈项: 补偿交叉耦合和反电势项。

典型形式:
ud_ref = PI_d + (Rs id - omega_e Lq iq)
uq_ref = PI_q + (Rs iq + omega_e Ld id + omega_e psi_f)

## 5. SVPWM 与逆变器
- 将 dq 电压参考变换为三相参考电压。
- 引入零序分量实现 SVPWM 调制。
- 占空比映射后得到三相桥臂驱动。
- DC 母线通过电容方程计算电压变化。

## 6. 机械与负载耦合
轴系采用集中参数刚性同轴模型:
- 扭矩平衡决定角加速度。
- 机械角速度积分得到机械角位置。
- 涡轮提供正向扭矩，泵提供负载扭矩。

## 7. 数值求解原理
使用四阶 Runge-Kutta（RK4）推进状态:
1) 计算 k1
2) 计算 k2
3) 计算 k3
4) 计算 k4
5) 按加权平均合并到下一时刻

相对于欧拉法，RK4 在相同步长下通常有更高精度和更好稳定性。

## 8. 固定转速模式的意义
在 fixed_speed_mode 打开时:
- d(omega_mech)/dt 设为 0
- d(theta_mech)/dt 设为常量 omega_mech_fixed

作用:
- 将机械动态从测试中剥离。
- 更专注地评估电流环参数和解耦效果。
