# 使用说明

## 1. 环境要求
- Linux
- g++ (支持 C++17)
- make
- Python（用于 notebook 绘图，可选）

## 2. 常用命令
- 构建:
  make
- 运行:
  make run
- 清理:
  make clean

注意:
当前 make run 会先执行 clean，再全量编译并运行。

## 3. 输出与查看
- 程序输出日志: build/log.xlsx
- 绘图 notebook: notebooks/plot.ipynb

典型流程:
1) 运行 make run。
2) 打开 notebook 并执行各绘图单元。
3) 观察电流、转速、扭矩、压力等波形。

## 4. 关键参数入口
统一配置文件:
- include/config/sim_config.h

重点参数:
- runtime.model_dt: 连续积分步长。
- runtime.control_dt: 控制更新周期。
- runtime.total_time: 仿真总时长。
- runtime.log_every_n_steps: 日志抽样步长。

电流环参数:
- current_loop.id_ref
- current_loop.iq_ref
- current_loop.kp_d, ki_d
- current_loop.kp_q, ki_q

可选模式:
- runtime.fixed_speed_mode
- runtime.omega_mech_fixed

## 5. 电流阶跃测试建议
如需测试 iq 跟踪能力，建议采用单点阶跃策略:
- 阶跃前参考: iq_ref_1
- 阶跃时刻: t_step
- 阶跃后参考: iq_ref_2

建议避免在同一控制周期内重复调用控制器两次，以免积分器更新被重复执行。

## 6. 常见问题排查
### 6.1 电流跟踪偏差大
优先检查:
- 参考值是否真的发生阶跃。
- 控制器是否开启了正常限幅与抗饱和逻辑。
- control_dt 是否过大。
- fixed_speed_mode 是否与测试目标一致。

### 6.2 波形看起来不连续
检查:
- log_every_n_steps 是否过大导致抽样太稀。
- notebook 是否读取了最新日志文件。

## 7. 修改后验证
每次改控制与求解逻辑后，建议执行:
1) make run
2) 对比 iq, id, uq_ref, omega_mech 关键曲线
3) 记录修改前后指标（稳态误差、超调、调节时间）
